# 🖥️ WhoAmIToYou_bot — Опрос.exe

**Release 1.1**

Обычный Telegram-опрос, наряженный в Windows XP: рабочий стол, «Пуск», панель задач, диалоговые окна — и внутри всего этого прячется настоящий вопрос.

> «Кем я для вас являюсь?»

Идея простая: а что, если бы опрос в Telegram был приложением из 2003 года? Поэтому здесь сохранены детали, без которых голосование прекрасно обошлось бы — просто так интереснее.

---

## ✨ Возможности

- Рабочий стол Windows XP: иконки, «Пуск», панель задач, часы
- Окно `Мой компьютер` с меню, тулбаром, боковой панелью и статус-баром
- Голосование с анимированными полосками результатов и конфетти
- Работающий калькулятор — единственное в интерфейсе, что не декорация (подробнее ниже)
- Экран загрузки в стиле Windows: интерфейс открывается только когда всё уже готово
- Просмотр результатов по паролю без голосования
- Сворачивание, разворачивание, перетаскивание окон
- Системный звук и иконка при ошибке — как в оригинале
- Защита от повторного голосования и от честной ошибки, выдаваемой за реальный сбой сети
- Адаптация под телефоны в любой ориентации

## 🧩 Как это работает

Открывается интерфейс, похожий на рабочий стол Windows XP. В окне `Мой компьютер` — вопрос:

**Кем я для вас являюсь?**

- Друг
- Возлюбленный
- Знакомый
- Хотите познакомиться
- Незнакомец
- Учимся вместе

После голоса: отправка в CountAPI → «Обработка…» с прогресс-баром → результаты с анимацией → конфетти → кнопка «Поделиться» в Telegram. Если запрос не прошёл — честная ошибка вместо фиктивного «Готово».

До голосования окно нельзя свернуть или закрыть — единственный тролль-момент в стиле XP, который здесь оставлен намеренно.

## 🧮 Калькулятор

Единственное в интерфейсе приложение, которое реально работает, а не просто выглядит как окно. Открывается из меню «Пуск».

Режим зависит от ориентации экрана — как в настоящей Windows, где ширина окна определяет доступные функции:

| Ориентация | Режим | Что внутри |
|---|---|---|
| Портрет | Обычный | Арифметика, память (MC/MR/MS/M+), √, 1/x, % |
| Альбомная | Инженерный | + основания счисления (Hex/Dec/Oct/Bin), тригонометрия с Градусы/Радианы/Грады и Inv/Hyp, log/ln, степени, n!, побитовые операции |

Кнопки `Sta` `Ave` `Sum` `Dat` `dms` `Exp` `(` `)` показаны для вида (в оригинале это отдельные функции — список чисел для статистики, стек выражений), но не подключены: для калькулятора внутри опроса это явно лишнее.

## 📁 Структура и запуск

```
.
├── index.html              # релиз — тот бот, который видят подписчики
├── index-<канал>.html      # тот же код под другой канал (см. ниже)
└── README.md
```

Открывается прямо в браузере, ничего ставить не нужно.

**GitHub Pages:** файл, который должен отвечать на корневой адрес репозитория (`https://username.github.io/repo/`), обязан называться `index.html` — так работает Pages. Другое имя — и по корневому адресу будет `File not found`.

**Telegram Mini App:** URL файла — в [@BotFather](https://t.me/BotFather) → Menu Button / Web App. Внутри Telegram автоматически подключаются `ready()`, `expand()`, цвета темы, haptics и MainButton для шаринга.

## 🔧 Настройка своего опроса

Всё — в объекте `CONFIG` внутри HTML:

```js
const CONFIG = {
  pollId: 'who-am-i-xp-release-1-0-1',
  channelName: '@opupevshiy_600321',
  question: 'Кем я для вас являюсь?',
  options: ['Друг', 'Возлюбленный', 'Знакомый', 'Хотите познакомиться', 'Незнакомец', 'Учимся вместе']
};
```

Новый `pollId` — новый счётчик с нуля. Пароль для просмотра результатов без голосования:

```js
const RESULTS_PASSWORD = '676988';
```

> ⚠️ Пароль лежит в открытом клиентском коде — это не настоящая защита, любой может посмотреть исходник страницы.

**Один опрос, разные каналы.** `index-<канал>.html` — тот же код с другими `pollId` и `channelName`. Заводя опрос под ещё один канал, проще всего скопировать существующий файл и поменять только эти два поля.

**Меняем вариант ответа, не теряя остальные голоса.** Не трогай `pollId` — вместо этого в коде есть `OPTION_KEY_IDS`: числовой id голосования для каждого варианта, не завязанный на его позицию в списке. Убери старый вариант из `options`, добавь новый на его место, и впиши в `OPTION_KEY_IDS` свежий, ещё не использованный номер вместо старого — тогда у нового варианта будет чистый счётчик, а остальные не пострадают.

## 📊 Данные

**Голоса** хранятся в [CountAPI](https://countapi.mileshilliard.com) — по ключу `<pollId>_optN` на каждый вариант. Ключи и значения там публичные, без авторизации: для опроса среди своих в канале нормально, но не защита от накрутки, если кто-то намеренно постучится в API напрямую. Если запрос не проходит — честная ошибка с кнопкой «Повторить», а не фиктивный ноль голосов.

**Повторное голосование** блокируется через `localStorage` (`voted_<pollId>`, `choice_<pollId>`) — работает на уровне браузера/устройства, не сервера.

## 🕓 История версий

### Release 1.1 (текущая)

Всё из Beta 1.1 перенесено в релиз как есть — калькулятор с обоими режимами, обработка ошибок, экран загрузки. Не перенесён только диалог согласия на бету: в релизе он не нужен. Подробности — в таблице ниже.

### Beta 1.1

Три этапа полировки перед переносом в релиз:

| Этап | Что сделано |
|---|---|
| NoRC | Общий с релизом счётчик голосов (сознательно, без отдельной песочницы); перенесена замена «Ненавидите меня» → «Учимся вместе»; добавлен калькулятор (первая версия); починено разворачивание окна на весь экран (обёртка окна с постоянным `transform` ломала позиционирование); честная ошибка вместо фиктивного «0 голосов» при сбое загрузки результатов; экран загрузки адаптирован под телефоны |
| RC | Найдена настоящая причина «вечной ошибки соединения»: у нового варианта ответа свежий, ещё не тронутый счётчик — CountAPI отвечает на него `404`, а прошлая правка принимала это за реальный сбой сети; калькулятор адаптирован под портретную ориентацию (три разных `auto`-размера подряд ломались непредсказуемо — заменены на одну явную формулу); добавлен диалог согласия на бету; `localStorage` обёрнут в try/catch (мог уронить весь скрипт в отдельных конфигурациях Telegram WebView); длинные сообщения об ошибках калькулятора больше не обрезаются |
| RC Final | Калькулятор пересобран по реальному скриншоту: три кнопки в шапке окна вместо одной, индикатор памяти перенесён на правильное место, кнопки перестали расползаться (кнопки xp.css по умолчанию не уже 75px — несовместимо с сеткой на ~38px на кнопку, перебито через `!important`), знак корня и выравнивание первой строки — как в оригинале; исправлена растяжка калькулятора на телефоне (конфликт CSS-специфичности со старым мобильным правилом для главного окна); добавлено переключение режимов по повороту экрана (портрет/альбомная); радиокнопки и чекбоксы переведены на разметку, которую ожидает xp.css |

### Release 1

Первый релиз: иконки сверены по репозиторию вместо угаданных наугад; честная ошибка вместо фиктивного успеха при сбое голосования; таскбар получил иконку и настоящий бевел; обои переведены на официальный редирект Wikipedia; убраны задвоенные CSS-правила и мёртвый код; добавлен вариант «Незнакомец», убрана «Электронная почта» (не нашлось иконки); файл переименован в `index.html` (без этого — `File not found` на GitHub Pages); ускорена загрузка (`preconnect`, `preload`, отложенные иконки).
