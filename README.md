# 🖥️ WhoAmIToYou_bot — Опрос.exe

![Version](https://img.shields.io/badge/version-1.1.3-0058a8?style=flat-square)
![Platform](https://img.shields.io/badge/platform-Telegram%20Mini%20App-26A5E4?style=flat-square)
![Status](https://img.shields.io/badge/status-release-2e7d32?style=flat-square)

Обычный Telegram-опрос, наряженный в Windows XP: рабочий стол, «Пуск», панель задач, диалоговые окна — и внутри всего этого прячется один простой вопрос.

> «Кем я для вас являюсь?»

А что, если бы опрос в Telegram был приложением из 2003 года? Поэтому здесь сохранены детали, без которых голосование прекрасно бы обошлось — просто так интереснее.

---

## ✨ Возможности

- Рабочий стол Windows XP: иконки, «Пуск», панель задач, часы
- Окно `Мой компьютер` с меню, тулбаром, боковой панелью и статус-баром
- Голосование с анимированными полосками результатов и конфетти
- Работающий калькулятор — единственное в интерфейсе, что не декорация
- Экран загрузки: открывает интерфейс, как только готово то, что видно сразу — остальное догружается в фоне
- Просмотр результатов по паролю без голосования
- Окна сворачиваются, разворачиваются и таскаются за шапку, как настоящие — включая восстановление кликом по панели задач
- Системный звук и иконка при ошибке
- Честная обработка сетевых сбоёв — без фиктивных «0 голосов» и мнимых «Готово»

---

## 🧩 Как это работает

Открывается интерфейс, похожий на рабочий стол Windows XP. В окне `Мой компьютер` — вопрос:

**Кем я для вас являюсь?**

Друг · Возлюбленный · Знакомый · Хотите познакомиться · Незнакомец · Учимся вместе

После голоса: отправка в CountAPI → «Обработка…» с прогресс-баром → результаты с анимацией → конфетти → кнопка «Поделиться» в Telegram. Если запрос не прошёл — честная ошибка вместо фиктивного «Готово».

До голосования окно нельзя свернуть или закрыть — единственный тролль-момент в стиле XP, оставленный здесь намеренно.

---

## 🧮 Калькулятор

Единственное окно в интерфейсе, которое реально работает, а не просто выглядит как окно. Открывается из меню «Пуск», сворачивается в панель задач, разворачивается кликом обратно — кнопка «развернуть на весь экран» при этом неактивна, точно как в оригинале.

Режим зависит от ориентации экрана — как в настоящей Windows, где ширина окна определяет доступные функции:

| Ориентация | Режим | Что внутри |
|---|---|---|
| 📱 Портрет | Обычный | Арифметика, память (MC/MR/MS/M+), √, 1/x, % |
| 💻 Альбомная | Инженерный | + Hex/Dec/Oct/Bin, тригонометрия (Градусы/Радианы/Грады, Inv/Hyp), log/ln, степени, n!, побитовые операции |

Кнопки `Sta` `Ave` `Sum` `Dat` `dms` `Exp` `(` `)` показаны для вида — в оригинале это отдельные большие фичи (список чисел для статистики, стек выражений), явно лишние для калькулятора внутри опроса.

## 📁 Структура и запуск

```
.
├── index.html              # релиз — тот бот, который видят подписчики
├── index-<канал>.html      # тот же код под другой канал
└── README.md
```

Открывается прямо в браузере, ничего ставить не нужно.

**GitHub Pages:** файл, отвечающий на корневой адрес репозитория, обязан называться `index.html` — так работает Pages. Другое имя даст `File not found` по адресу `https://username.github.io/repo/`.

**Telegram Mini App:** URL файла — в [@BotFather](https://t.me/BotFather) → Menu Button / Web App.

## 🔧 Настройка своего опроса

```js
const CONFIG = {
  pollId: 'who-am-i-xp-release-1-0-1',
  channelName: '@opupevshiy_600321',
  question: 'Кем я для вас являюсь?',
  options: ['Друг', 'Возлюбленный', 'Знакомый', 'Хотите познакомиться', 'Незнакомец', 'Учимся вместе']
};
```

Новый `pollId` — новый счётчик с нуля. Пароль для просмотра результатов без голосования лежит рядом, в `RESULTS_PASSWORD` — учти, это открытый клиентский код, не настоящая защита.

**Один опрос, разные каналы:** `index-<канал>.html` — тот же код с другими `pollId` и `channelName`.

**Меняем вариант ответа, не теряя остальные голоса:** не трогай `pollId`. В коде есть `OPTION_KEY_IDS` — числовой id голосования для каждого варианта, не завязанный на его позицию в списке. Убери старый вариант из `options`, добавь новый на его место, впиши в `OPTION_KEY_IDS` свежий номер вместо старого — у нового варианта будет чистый счётчик, остальные не пострадают.

## 📊 Данные

Голоса хранятся в [CountAPI](https://countapi.mileshilliard.com) по ключу `<pollId>_optN`. Ключи и значения там публичные, без авторизации — нормально для опроса среди своих, но не защита от накрутки, если кто-то специально постучится в API напрямую.

Повторное голосование блокируется через `localStorage` — работает на уровне браузера/устройства, не сервера.

## 🕓 История релизов

### 1.1.3 (текущая)

- **Анимация появления перенесена туда, где и задумывалась — на панель задач.** Не экран загрузки уезжает эффектно, а «Пуск» и панель задач въезжают на своё место снизу вверх, с небольшой задержкой после появления рабочего стола — сначала стол, затем следом панель
- **Фоновая подгрузка теперь незаметна умышленно, а не только по счастливой случайности.** Иконки меню «Пуск» и калькулятора, если ещё не успели догрузиться к моменту открытия, плавно проявляются, а не выскакивают рывком — независимо от того, догрузились они за секунду до открытия или ровно в момент открытия
- **Приоритеты загрузки расставлены заново.** Всё, что видно сразу (иконки рабочего стола, окна, тулбара, адресной строки, панели задач) — высокий приоритет. Найден и исправлен пропуск: сам адрес сервера голосования (CountAPI) не был заранее «прогрет» соединением — первый же голос или запрос результатов раньше платил полную цену установки соединения с нуля. Теперь это соединение готовится заранее, как и для остальных внешних адресов

### 1.1.2

- **Изменён сам механизм загрузки.** Раньше экран загрузки ждал вообще всё на странице — вплоть до иконок калькулятора и меню «Пуск», которые не видны, пока их не откроют. Теперь он ждёт только то, что действительно видно сразу: обои, стили, иконки рабочего стола и окна опроса. Всё остальное — меню «Пуск», калькулятор — продолжает грузиться в фоне уже после появления интерфейса, ничего не блокируя
- **Экран загрузки уходит вверх и за пределы экрана**, а не просто растворяется — контент под ним открывается снизу вверх, плавно и заметно, а не появляется рывком
- Иконкам рабочего стола и окна выставлен явный высокий приоритет загрузки — раз теперь их меньше в очереди, пусть освобождающийся канал достаётся именно им
- Найден и исправлен реальный баг: при одной из более ранних правок в разметке образовался задвоенный `<div>` — страница всё равно работала (браузеры прощают такое), но это мёртвый груз, который стоило убрать

### 1.1.1

- Клик по панели задач теперь переключает окно в обе стороны (свернуть ⇄ восстановить), а не только восстанавливает — как в настоящей Windows
- Кнопка «развернуть» на калькуляторе стала по-настоящему `disabled`, а не просто без реакции на клик — внешне и физически неактивна, как в оригинале
- Иконки, скрытые до открытия меню «Пуск» или калькулятора, тогда впервые получили пониженный приоритет загрузки
- Убран мёртвый CSS, оставшийся с самых первых версий и никогда не применявшийся

### 1.1

- **Калькулятор** — первое по-настоящему работающее приложение в интерфейсе, а не просто окно для вида. Открывается из меню «Пуск», сворачивается и таскается как настоящее окно. Два режима в зависимости от ориентации экрана:
  - Портрет — обычный: арифметика, память (MC/MR/MS/M+), √, 1/x, %
  - Альбомная — инженерный: + Hex/Dec/Oct/Bin, тригонометрия (Градусы/Радианы/Грады, Inv/Hyp), log/ln, степени, n!, побитовые операции
- **Починено разворачивание окна на весь экран** — раньше окно улетало в случайное место вместо полного экрана из-за конфликта позиционирования у обёртки окна
- **Найдена настоящая причина «вечной ошибки соединения»** — она была не в сети. У нового варианта ответа «Учимся вместе» совсем свежий счётчик голосов, CountAPI отвечает на такой ключ `404` — это нормально, а не сбой. Прошлая версия принимала любой не-200 ответ за реальную сетевую проблему и показывала ошибку постоянно
- **Честная обработка сбоя загрузки результатов** — если запрос к счётчику не прошёл, раньше молча показывался «0 голосов», от настоящего нуля не отличить. Теперь — понятная ошибка с кнопкой «Повторить»
- **`localStorage` защищён от исключений** — в отдельных конфигурациях Telegram WebView (приватный режим, ограничения хранилища) обращение к нему могло уронить весь скрипт при запуске. Теперь в этом случае просто не запоминается голос, но приложение не падает целиком
- Экран загрузки в стиле Windows — интерфейс открывается только когда все обои, иконки и стили реально готовы, без «прыгающих» элементов
- Вариант ответа «Ненавидите меня» заменён на «Учимся вместе» без сброса счётчиков остальных вариантов

### Release 1

Иконки сверены по репозиторию вместо угаданных наугад; честная ошибка вместо фиктивного успеха при сбое голосования; таскбар получил иконку и настоящий бевел; обои переведены на официальный редирект Wikipedia; убраны задвоенные CSS-правила и мёртвый код; добавлен вариант «Незнакомец», убрана «Электронная почта»; файл переименован в `index.html` (без этого — `File not found` на GitHub Pages); ускорена загрузка (`preconnect`, `preload`, отложенные иконки).

## 🧪 История беты

Отдельная от релиза ветка (`index-beta.html`) для обкатки более рискованных вещей перед переносом. Всё, что сейчас в релизе 1.1, прошло через неё — три этапа полировки под общим именем **Beta 1.1**:

| Этап | Что сделано |
|---|---|
| **NoRC** | Общий с релизом счётчик голосов (сознательно, без отдельной песочницы); перенесена замена «Ненавидите меня» → «Учимся вместе»; добавлен калькулятор (первая версия); починено разворачивание окна на весь экран; честная ошибка вместо фиктивного «0 голосов» при сбое загрузки результатов; экран загрузки адаптирован под телефоны |
| **RC** | Найдена настоящая причина «вечной ошибки соединения» (см. выше); калькулятор адаптирован под портретную ориентацию — три разных `auto`-размера подряд ломались непредсказуемо, заменены на одну явную формулу; добавлен диалог согласия на бету («это бета-версия, продолжить?»); `localStorage` обёрнут в try/catch; длинные сообщения об ошибках калькулятора больше не обрезаются |
| **RC Final** | Калькулятор пересобран по реальному скриншоту оригинала: три кнопки в шапке вместо одной, индикатор памяти перенесён на правильное место, кнопки перестали расползаться (у библиотеки стилей кнопки по умолчанию не уже 75px — несовместимо с сеткой на ~38px на кнопку), знак корня и выравнивание первой строки — как в оригинале; исправлена растяжка калькулятора на телефоне (конфликт CSS-специфичности со старым мобильным правилом для главного окна); добавлено переключение режимов по повороту экрана (портрет/альбомная); радиокнопки и чекбоксы переведены на разметку, которую ожидает библиотека стилей |

Диалог согласия на бету («Принять» / «Отклонить») существует только здесь — в релиз не переносится, там он не нужен.
