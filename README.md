# 🖥️ WhoAmIToYou_bot — Опрос.exe

**Версия 1.0.1.1**

**Интерактивный опрос в стиле Windows XP Luna**, сделанный как Telegram Web App.

Обычный опрос превращается в полноценное окно Windows XP: рабочий стол, меню «Пуск», панель задач, классические диалоги, анимация и немного ностальгии.

> «Кем я для вас являюсь?»

Это релизная версия проекта — стабильная, проверенная и готовая к публикации в канале.

---

## ✨ Возможности

- 🪟 Полный интерфейс в стиле **Windows XP Luna**
- ⏳ Экран загрузки в стиле Windows — интерфейс открывается только когда всё готово, без «прыгающих» иконок
- 💻 Рабочий стол с иконками, «Пуск» и панелью задач
- 📂 Окно `Мой компьютер` с меню, тулбаром и статус-баром
- 📊 Голосование с анимированными полосками результатов
- 🎉 Конфетти после успешного голоса
- 🔊 Системный звук ошибки — как в настоящей XP
- 🔔 Haptic Feedback внутри Telegram
- 📤 Кнопка «Поделиться результатом»
- 🗕 Сворачивание / разворачивание / перетаскивание окна
- 🔐 Просмотр результатов по паролю (для тех, кто ещё не голосовал)
- 💾 Защита от повторного голосования через `localStorage`
- 📱 Адаптация под мобильные устройства
- 🖼️ Иконки выверены по оригинальному репозиторию (не наугад)

## 🧩 Как это работает

После открытия пользователь видит интерфейс, максимально похожий на рабочий стол Windows XP.

В окне `Мой компьютер` — вопрос:

**Кем я для вас являюсь?**

Варианты ответа:

- Друг
- Возлюбленный
- Знакомый
- Хотите познакомиться
- Незнакомец
- Учимся вместе

После голосования происходит следующее:

1. Голос отправляется в CountAPI
2. Показывается окно «Обработка голоса…» с прогресс-баром
3. Если запрос не прошёл — честно показывается ошибка (со звуком) и можно попробовать снова, а не мнимое «Готово»
4. При успехе — подтверждается отправка
5. Отображаются результаты с анимацией
6. Запускается конфетти
7. В Telegram появляется кнопка «Поделиться результатом»

До голосования окно нельзя свернуть или закрыть — классический троллинг в стиле XP.

## 🚀 Запуск

### 1. Локально

Просто открой файл:

```
index.html
```

в любом современном браузере.

### 2. GitHub Pages

1. Загрузи `index.html` **в корень репозитория** (не в подпапку, если не планируешь потом добавлять `/docs` в путь)
2. Перейди в **Settings → Pages**
3. Выбери ветку `main` и папку `/`
4. Сохрани

Через минуту приложение будет доступно по адресу вида:

```
https://<username>.github.io/<repo>/
```

> ⚠️ Если увидел `File not found` от GitHub Pages — почти всегда это значит, что в репозитории нет файла `index.html` ровно в том месте, куда указывает URL (либо файл называется иначе, либо лежит не в той папке/ветке). Переименование в `index.html` в корне решает это в 99% случаев.

### 3. Telegram Mini App

Укажи URL файла в [@BotFather](https://t.me/BotFather) → Menu Button / Web App.
При запуске внутри Telegram автоматически вызываются:

- `Telegram.WebApp.ready()`
- `Telegram.WebApp.expand()`
- изменение цветов интерфейса
- тактильная обратная связь
- MainButton для шаринга

## 🔧 Настройка своего опроса

Все основные параметры находятся в объекте `CONFIG` внутри HTML:

```js
const CONFIG = {
  pollId: 'who-am-i-xp-release-1-0-1',  // уникальный ID опроса
  channelName: '@opupevshiy_600321',    // название канала / автора
  question: 'Кем я для вас являюсь?',
  options: [
    'Друг',
    'Возлюбленный',
    'Знакомый',
    'Хотите познакомиться',
    'Незнакомец',
    'Учимся вместе'
  ]
};
```

Рекомендуется менять `pollId` при каждом новом опросе, чтобы счётчики не пересекались — новый ID всегда стартует с нуля.

### Два канала, один код

С версии 1.0.1.1 проект существует в двух копиях — `index.html` и `index-<канал>.html` — с одинаковым кодом, но своим `pollId` и `channelName` в каждой. Заводя опрос под третий канал, проще всего скопировать один из существующих файлов и поменять только эти два поля.

### Меняем вариант ответа, не теряя остальные голоса

Если нужно заменить формулировку одного варианта, не сбрасывая счётчики остальных — **не трогай `pollId`**. Вместо этого в коде есть `OPTION_KEY_IDS`: массив, который привязывает каждый вариант к своему числовому id в CountAPI (id не совпадает напрямую с позицией в списке). Убери старый вариант из `options`, добавь новый на его место — и **добавь в `OPTION_KEY_IDS` новый, ещё не использованный номер** для этой позиции вместо старого. Так у нового варианта будет чистый счётчик с нуля, а остальные не пострадают.

Пароль для просмотра результатов без голосования:

```js
const RESULTS_PASSWORD = '676988';
```

> ⚠️ Пароль лежит в клиентском JavaScript. Это удобно, но **не является настоящей защитой**. Любой может посмотреть исходный код страницы. Если нужна реальная безопасность — выноси проверку на сервер.

## 📊 Хранение результатов

Используется [CountAPI](https://countapi.mileshilliard.com) — открытый счётчик-сервис на отдельном сервере энтузиаста.

Для каждого варианта создаётся отдельный ключ:

```
<pollId>_opt0
<pollId>_opt1
<pollId>_opt2
...
```

При голосовании увеличивается соответствующий счётчик, при просмотре результатов — запрашиваются актуальные значения.

> ⚠️ Ключи и значения в CountAPI публичны и не защищены авторизацией — это подходит для голосования среди своих в канале, но не является защитой от накрутки, если кто-то намеренно захочет постучаться в API напрямую.

Если запрос к API не проходит (нет сети, сервис недоступен), приложение честно сообщает об ошибке и не притворяется, что голос принят.

## 💾 Защита от повторного голосования

После успешного голоса в `localStorage` сохраняются два ключа:

```
voted_<pollId>
choice_<pollId>
```

Это позволяет:

- не показывать форму повторного голосования
- сразу открывать результаты при повторном заходе
- помнить, какой вариант выбрал пользователь

> Ограничение работает только на уровне браузера/устройства. Это не серверная защита от накрутки.

## 🎨 Дизайн

Интерфейс вдохновлён Windows XP и использует:

- тему **Luna**
- классические XP-иконки, сверенные вручную по исходному репозиторию (у части файлов там непрозрачные числовые названия без подписи, поэтому иконки подбирались и проверялись по одной)
- меню «Пуск» и панель задач с иконкой приложения на кнопке
- статус-бар и диалоговые окна с системной иконкой ошибки
- системный звук ошибки
- характерные градиенты и рамки

Радиокнопки и кнопки специально не переопределены собственными стилями — за это отвечает XP.css, и получается ближе к оригиналу, чем самодельный градиент.

Графические ресурсы подгружаются из:

- [ShizukuIchi/winXP](https://github.com/ShizukuIchi/winXP) — иконки и звук ошибки
- Wikipedia (через `Special:FilePath`, чтобы не зависеть от конкретного хеша файла) — обои Bliss
- unpkg — XP.css

Для полноценной работы нужен доступ в интернет.

## 🕓 История версий

### 1.0.1.1 (текущая)

- Вариант ответа «Ненавидите меня» заменён на «Учимся вместе»
- `pollId` **не менялся** — голоса за остальные 5 вариантов сохранены. Технически это устроено через отдельный числовой id голосования у каждого варианта (не завязан на его позицию в списке): у нового варианта — свежий, ранее не использованный id, поэтому он стартует с нуля и не наследует старые голоса за убранный вариант
- С этой версии проект ведётся как **два параллельных релиза** с одинаковым кодом, но разным `pollId` и `channelName` — свой на каждый канал. При будущих правках оба файла обновляются синхронно

> ℹ️ Починенные в бете (`beta 1.1 NoRC`) баги с перетаскиванием+разворачиванием окна и с честной обработкой сбоя загрузки результатов в этот релиз пока **не перенесены** — только текущая правка со списком вариантов.

### 1.0.1

- **Экран загрузки** в стиле Windows — закрывает интерфейс, пока реально не подгрузится всё: обои, иконки, стили. Раньше элементы могли появляться по одному, теперь человек сразу видит готовую картинку
- Иконки меню «Пуск» и аватар раньше грузились лениво (только при открытии меню) — теперь грузятся сразу вместе со всем остальным, пока виден экран загрузки, иначе он бы их не дождался
- Обои возвращены к разрешению 1920px — раз загрузка теперь скрыта экраном, качеством можно не жертвовать
- **Починено разворачивание окна на весь экран** — раньше окно «улетало» в произвольное место вместо полного экрана. Причина: у обёртки окна был постоянный CSS `transform`, из-за чего она становилась точкой отсчёта для `position:fixed` внутреннего окна вместо реального экрана
- **Пароль для результатов больше никак не пересекается с голосованием** — ни в счётчике вариантов, ни в данных браузера, это отдельный флаг доступа. При этом пароль, как и раньше, открывает доступ к результатам при повторном заходе и теперь дополнительно разблокирует перетаскивание/сворачивание/закрытие окна — наравне с реальным голосованием, но без начисления голоса
- «Мой компьютер» и «Опрос.exe» поменялись местами: открытое окно (локация, которую «просматриваешь») теперь называется «Мой компьютер», а ярлык на рабочем столе — «Опрос.exe»
- Убран пункт «Панель управления» из меню «Пуск» — подходящая иконка для него не подтверждена, а лишний пункт не нужен
- `pollId` снова сброшен на новое значение — счётчики стартуют с нуля

### release — первый релиз

- **Баг с «ложным успехом»**: при сбое запроса к CountAPI голос раньше всё равно засчитывался как успешный. Теперь при реальном сбое сети показывается честная ошибка (со звуком), а не фиктивное «Готово»
- **Иконки**: часть исходных иконок была подобрана наугад и не совпадала по смыслу (например, у корзины была иконка папки с нотой, у «Мультимедиа» — блокнот). Все иконки сверены вручную по репозиторию ShizukuIchi/winXP и расставлены заново
- **Таскбар**: кнопка свёрнутого окна получила иконку приложения и настоящий выпуклый/вдавленный XP-бевел вместо плоского прямоугольника
- **Обои**: ссылка на Bliss переведена на официальный редирект Wikipedia (`Special:FilePath`), чтобы не зависеть от возможно неверного хеша файла
- **Чистка кода**: убраны задвоенные CSS-правила (следы правок в несколько заходов), мёртвый код, приведена в порядок разметка кнопок (`type="button"` везде)
- **Новый вариант ответа** — «Незнакомец»
- **Пункт «Электронная почта»** убран из меню «Пуск» — не нашлось подходящей иконки, решили не гадать
- **Добавлены** «Блокнот» и «Калькулятор» в меню «Пуск», системный звук ошибки, иконка ошибки в диалогах
- **Файл переименован в `index.html`** — старое имя вызывало `File not found` на корневом адресе GitHub Pages, так как Pages ищет именно `index.html`
- **Скорость загрузки**: `preconnect` на внешние источники, `preload` для обоев с приоритетом, размер обоев временно уменьшен, иконки меню «Пуск» отложены до открытия

## 🧪 Бета

Отдельная от релиза ветка (`index-beta.html`) для обкатки более рискованных вещей перед переносом в релиз. Открывается только под каналом автора — двух каналов, как у релиза, тут не предусмотрено.

### beta 1.1 NoRC (текущая)

- **`pollId` — тот же, что у релиза** (`who-am-i-xp-release-1-0-1`), сознательно. Отдельного счётчика для беты нет: любой голос, поданный при тестировании в бете, попадёт в тот же счётчик, что видят подписчики в релизе
- Из релиза сюда так же перенесена замена «Ненавидите меня» → «Учимся вместе» (тем же способом через `OPTION_KEY_IDS`, без сброса счётчика)
- **Работающий калькулятор** — первое по-настоящему рабочее приложение внутри интерфейса (всё остальное — декорация). Открывается из меню «Пуск», своё окно, перетаскивается за шапку. Реализованы память (MC/MR/MS/M+), корень, 1/x, %, +/-, backspace, деление на ноль показывает ошибку как в оригинале. Кнопки — без своих стилей, оформление берёт из xp.css, как и везде в проекте
- **Починено разворачивание окна после перетаскивания** — раньше при попытке развернуть уже сдвинутое окно получалось нечто нечитаемое. Причина: перетаскивание задаёт позицию через inline-стили, у которых приоритет выше, чем у CSS-класса `.maximized`, — окно меняло размер, но не позицию. Теперь при разворачивании inline-стили явно сбрасываются, а при восстановлении — возвращаются как было
- **Честная обработка сбоя при загрузке результатов** — если запрос счётчика не прошёл (сеть, лимит API), результаты раньше молча показывали "0 голосов" — от настоящего нуля не отличить, выглядело как пустой/сломанный опрос. Теперь в этом случае — понятное сообщение об ошибке и кнопка «Повторить»
- Экран загрузки адаптирован под телефоны — гифка масштабируется в первую очередь по ширине, с отступами под безопасную зону экрана
- В заголовке вкладки — пометка `[BETA 1.1 NoRC]`, чтобы не перепутать с релизом

> ⚠️ Фиксы с разворачиванием окна и честной обработкой сбоя результатов пока не перенесены в релиз — только здесь.
