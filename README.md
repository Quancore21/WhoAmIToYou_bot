# 🖥️ WhoAmIToYou_bot — Опрос.exe

**Интерактивный опрос в стиле Windows XP Luna**, сделанный как Telegram Web App.

Обычный опрос превращается в полноценное окно Windows XP: рабочий стол, меню «Пуск», панель задач, классические диалоги, анимация и немного ностальгии.

> «Кем я для вас являюсь?»

---

## ✨ Возможности

- 🪟 Полный интерфейс в стиле **Windows XP Luna**
- 💻 Рабочий стол с иконками, «Пуск» и панелью задач
- 📂 Окно `Опрос.exe` с меню, тулбаром и статус-баром
- 📊 Голосование с анимированными полосками результатов
- 🎉 Конфетти после успешного голоса
- 🔔 Haptic Feedback внутри Telegram
- 📤 Кнопка «Поделиться результатом»
- 🗕 Сворачивание / разворачивание / перетаскивание окна
- 🔐 Просмотр результатов по паролю (для тех, кто ещё не голосовал)
- 💾 Защита от повторного голосования через `localStorage`
- 📱 Адаптация под мобильные устройства

---

## 🧩 Как это работает

После открытия пользователь видит интерфейс, максимально похожий на рабочий стол Windows XP.

В окне `Опрос.exe` — вопрос:

**Кем я для вас являюсь?**

Варианты ответа:

- Друг  
- Возлюбленный  
- Знакомый  
- Хотите познакомиться  
- Ненавидите меня  

После голосования происходит следующее:

1. Голос отправляется в CountAPI  
2. Показывается окно «Обработка голоса…» с прогресс-баром  
3. Подтверждается успешная отправка  
4. Отображаются результаты с анимацией  
5. Запускается конфетти  
6. В Telegram появляется кнопка «Поделиться результатом»

До голосования окно нельзя свернуть или закрыть — классический троллинг в стиле XP.

## 🚀 Запуск

### 1. Локально

Просто открой файл:

```
who-am-i-poll-xp-classic.html
```

в любом современном браузере.

### 2. GitHub Pages

1. Загрузи HTML-файл в репозиторий  
2. Перейди в **Settings → Pages**  
3. Выбери ветку `main` и папку `/`  
4. Сохрани  

Через минуту приложение будет доступно по адресу вида:

```
https://<username>.github.io/<repo>/
```

Укажи URL файла в [@BotFather](https://t.me/BotFather) → Menu Button / Web App.

- `Telegram.WebApp.ready()`
- `Telegram.WebApp.expand()`
- изменение цветов интерфейса
- тактильная обратная связь
- MainButton для шаринга

## 🔧 Настройка своего опроса

Все основные параметры находятся в объекте `CONFIG` внутри HTML:

```js
const CONFIG = {
  pollId: 'who-am-i-xp-v2-live',        // уникальный ID опроса
  channelName: '@opupevshiy_600321',   // название канала / автора
  question: 'Кем я для вас являюсь?',
  options: [
    'Друг',
    'Возлюбленный',
    'Знакомый',
    'Хотите познакомиться',
    'Ненавидите меня'
  ]
};
```

Рекомендуется менять `pollId` при каждом новом опросе, чтобы счётчики не пересекались.

Пароль для просмотра результатов без голосования:

```js
const RESULTS_PASSWORD = '676988';
```

> ⚠️ Пароль лежит в клиентском JavaScript. Это удобно, но **не является настоящей защитой**. Любой может посмотреть исходный код страницы. Если нужна реальная безопасность — выноси проверку на сервер.

## 📊 Хранение результатов

Используется [CountAPI](https://countapi.mileshilliard.com).

Для каждого варианта создаётся отдельный ключ:

```
<pollId>_opt0
<pollId>_opt1
<pollId>_opt2
...
```

При голосовании увеличивается соответствующий счётчик, при просмотре результатов — запрашиваются актуальные значения.

---

## 💾 Защита от повторного голосования

После успешного голоса в `localStorage` сохраняются два ключа:

```
voted_<pollId>
choice_<pollId>
```

Это позволяет:

- не показывать форму повторного голосования  
- сразу открывать результаты при повторном заходе  
- помнить, какой вариант выбрал пользователь  

> Ограничение работает только на уровне браузера/устройства. Это не серверная защита от накрутки.
